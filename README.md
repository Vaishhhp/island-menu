# Island Menu

Green accent buttons

The overall feeling should be modern, calm, elegant, friendly and premium, not overly colorful or corporate.

Main customer page

Create a single scrolling mobile menu for Seven Island Cafe.

At the top:

Seven Island Cafe logo/name

Small welcoming text such as "Good food, good moments."

A subtle language/menu icon if appropriate

A horizontal scrollable category navigation

Categories:

Coffee

Breakfast

Mains

Snacks

Desserts

Beverages

When a category is selected, smoothly scroll to that section.

Food cards

Display food items in a visually rich way similar to the reference image:

Large rounded food image

Item name

Short appetizing description

Price

Small dietary tag where relevant

Green circular or rounded "+" Add button

Use realistic café food images as placeholders.

Example items:

Cappuccino — ₹160

Classic Latte — ₹180

Grilled Cheese Sandwich — ₹220

Creamy Pasta — ₹280

Chicken Sandwich — ₹240

Chocolate Brownie — ₹150

Classic Cheesecake — ₹220

Cold Coffee — ₹180

Ordering interaction

When the user taps +, add the item to the cart.

Show a floating/sticky cart button at the bottom: "View Order • 2 items • ₹340"

When clicked, open a clean order summary showing:

Selected items

Quantity controls

Price

Total

Table number

Place Order button

For this prototype, the ordering interaction can be frontend-only with sample data.

Important UX

Mobile-first design

Smooth vertical scrolling

Horizontal category scrolling

Large touch-friendly buttons

Fast and uncluttered

Lots of whitespace

Rounded image cards

Subtle hover/tap animations

Sticky cart at the bottom

Fully responsive on mobile and desktop

Do NOT make it look like a generic restaurant POS system. It should feel like a beautiful digital extension of Seven Island Cafe.

Keep the first version focused only on browsing the menu and placing an order. Do not add inventory, payments, loyalty programs, reservations, analytics, or other unnecessary features.LOGO IS PROVIDED
